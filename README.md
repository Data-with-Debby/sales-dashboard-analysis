Power BI project analyzing sales performance and generating business insights

## 📊 Project Overview
This project analyzes sales performance using Power BI to uncover trends, evaluate profitability, and support data-driven decision-making.

## 🛠 Tools Used
- Power BI
- Microsoft Excel

## 📁 Dataset
The dataset includes sales transactions covering product categories, profit, quantity, discount, and order data across multiple years.

## 📈 Key Metrics
- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Profit Margin: 12%
- Total Quantity Sold: 37,873
- Total Orders: 5,009
- Average Discount: 0.16

## 📊 Key Insights
- Technology category generated the highest profit (~$145K)
- Office Supplies followed with strong performance (~$122K profit)
- Furniture recorded significantly lower profit (~$18K), indicating potential inefficiencies
- Sales trend shows fluctuations with peaks towards the end of the year
- Discounts have a varying impact on profit across product sub-categories
